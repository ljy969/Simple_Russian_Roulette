# 自定义俄罗斯转盘游戏

一个基于纯 HTML、CSS 与 JavaScript 实现的浏览器端俄罗斯转盘模拟游戏。支持自定义弹巢配置、主题切换及音效反馈，无需任何外部依赖，单文件即可运行。

---

## 功能特性

- **自定义弹巢配置**：可自由设定子弹总数（2–20）与实弹数量，虚弹数量自动计算。
- **随机装弹**：一键生成随机子弹总数与实弹分布。
- **无放回抽样机制**：每次扣动扳机后，已击发的弹巢位不再重复，真实模拟逐发射击过程。
- **转动轮盘**：重新洗牌弹巢顺序并重置击发位置。
- **重新装弹**：恢复初始弹巢配置，重新开始当前局。
- **深浅色主题**：支持浅色、深色及跟随系统三种模式，用户偏好通过 `localStorage` 持久化。
- **音效反馈**：击发实弹、空仓及转动轮盘时播放对应音效。

## 使用方法

本项目为单一 HTML 文件，无需构建工具或服务器环境。

1. 克隆或下载本仓库。
2. 使用任意现代浏览器直接打开 `index.html` 即可运行。

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
# 双击 index.html 或在浏览器中打开
```

## 操作说明

| 操作 | 说明 |
|------|------|
| 设置子弹 | 根据输入框中的子弹总数与实弹数量初始化弹巢 |
| 随机设置 | 随机生成 3–12 颗子弹及对应实弹数量 |
| 扣动扳机 | 击发当前弹巢位，判定实弹或空包弹 |
| 转动轮盘 | 重新洗牌弹巢顺序，重置击发索引 |
| 重新装弹 | 以当前输入参数重新初始化弹巢 |
| 主题切换 | 右上角三个按钮分别对应浅色、深色、跟随系统 |

## 主题系统

项目通过 CSS 自定义属性（Custom Properties）实现主题管理，支持以下三种模式：

- **浅色模式**：强制使用浅色配色方案。
- **深色模式**：强制使用深色配色方案。
- **跟随系统**：监听 `prefers-color-scheme` 媒体查询，实时响应操作系统主题变更。

用户选择的主题偏好存储于 `localStorage`，刷新页面后自动恢复。同时通过 `color-scheme` 属性确保浏览器原生控件（滚动条、数字输入框等）与当前主题保持一致。

---

## 技术实现

- **语言**：HTML5 / CSS3 / Vanilla JavaScript（ES6+）
- **洗牌算法**：Fisher-Yates 洗牌，保证弹巢排列均匀随机。
- **主题切换**：基于 `data-theme` 属性与 CSS 变量，无 JavaScript 框架依赖。
- **音效**：通过 Web Audio API（`HTMLAudioElement`）加载远程音频资源。
